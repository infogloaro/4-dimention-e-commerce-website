# Error codes

> Generated from `server/core/errors.ts` by `npm run docs:api`.

Every failure returns `{ "success": false, "error": { "code", "message", "details" }, "requestId" }`. Switch on `error.code`, never on `message`. `details` is code-specific (e.g. `VALIDATION_ERROR` → `{ fields: [{ path, code, message }] }`, `INSUFFICIENT_STOCK` → `{ variantId, available, requested }`).
